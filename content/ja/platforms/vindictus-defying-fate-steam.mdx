## システム要件：あなたのPCでVindictus Defying Fateは動くか？

ここがストアページの真価が発揮される部分だ。NEXONは具体的な最低要件と推奨要件を公開しており、その差は意味のあるものだ。

| コンポーネント | 最低 | 推奨 |

| OS | Windows 10（64ビット） | Windows 10（64ビット） |
| プロセッサー | Intel Core i5-9400F @ 2.9GHz / AMD Ryzen 7 1800X @ 3.6GHz | Intel Core i7-10700K @ 3.8GHz / AMD Ryzen 7 3700X @ 3.6GHz |
| グラフィックス | NVIDIA GeForce GTX 1060（6GB）/ AMD Radeon RX 480（8GB） | NVIDIA GeForce RTX 3060 / AMD Radeon RX 5700 XT |
| 追加情報 | 64ビットのプロセッサーとOSが必要 | 64ビットのプロセッサーとOSが必要 |

実用的なポイントをいくつか挙げる。

- **最低GPUは決して低くない。** 6GBのVRAMを搭載したGTX 1060は、形式的なものではなく本当の下限だ。内蔵グラフィックスでは到底太刀打ちできない。
- **推奨構成は1440pクラスのハードウェアを想定。** RTX 3060やRX 5700 XTという指定は、ゲームがうまくスケールするものの、新しいカードほど有利であることを示している。
- **メモリとストレージはまだ記載されていない。** とはいえ、3Dダンジョンを持つアクションRPGは常にアセットを読み込むため、最新のSSDを想定しておこう。
- **Windows 10が明記された基準。** ページにはWindows 11の記載がないが、これは発売前のページとしては普通のことだ。

自分のマシンが2つの構成の間に位置するなら、発売が近づいてベンチマークが出るまで何も買わないのが安全だ。

## SteamでVindictus Defying Fateをウィッシュリストに追加する方法

ウィッシュリストへの追加は、今できる最も有用な行動だ。Steamが発売日、予約受付、割引について通知するかどうかはこれで決まる。また、需要のシグナルにもなり、パブリッシャーがどれだけマーケティング予算を投じるかを決める際に重要となる。

| ステップ | 操作 |
| --- | --- |
| 1 | Steamアカウントにサインインする |
| 2 | [Vindictus: Defying Fate公式Steamストアページ](https://store.steampowered.com/app/2814860/Vindictus_Defying_Fate/)を開く |

追加のヒントをいくつか。

- **ウィッシュリストだけでなくフォローも。** フォローするとお知らせの通知が届き、毎月の開発ログもそこから受け取れる。
- **発売前に要件を確認。** ハードウェア要件が発売後に緩くなることはほとんどない。
- **サードパーティのキー転売業者は無視。** NEXONが公式の予約受付を発表するまで、合法的に購入できるものは何もない。
- **定期的にページを再確認。** 発売前のページは、仕様や機能が確定するにつれて頻繁に変更される。

Vindictus Defying FateのSteamページには現在、価格も購入オプションも表示されていない。そのため、ウィッシュリストへの追加が本当に唯一の行動だ。
